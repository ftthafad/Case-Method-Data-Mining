# Data

Dataset **Online Retail II** tidak disertakan karena ukurannya besar.

1. Unduh dari UCI Machine Learning Repository:
   https://archive.ics.uci.edu/dataset/502/online+retail+ii
   (Chen, D. (2019). *Online Retail II* [Dataset]. UCI Machine Learning Repository.)
2. Simpan sebagai `data/online_retail_II.xlsx` (berisi dua lembar: 2009-2010 dan 2010-2011).

Atau jalankan `python run_all.py --input <lokasi file>`.
